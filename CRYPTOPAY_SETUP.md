# Настройка CryptoPay для GoldenShake

## 1. Создание приложения в @CryptoBot
1. Откройте [t.me/CryptoBot](https://t.me/CryptoBot).
2. Перейдите в **My Apps**.
3. Нажмите **Create App**.
4. Укажите название приложения и подтвердите создание.

## 2. Какой токен нужен
Для GoldenShake нужен основной токен приложения:

```env
CRYPTOPAY_TOKEN=your_token_here
```

Именно этот токен используется для:
- создания инвойсов;
- проверки подписи webhook;
- подтверждения оплат в гарант-сделках и депозитах.

## 3. Куда вставлять токен
Откройте файл `.env` на сервере и добавьте строку:

```env
CRYPTOPAY_TOKEN=your_token_here
```

После изменения `.env` перезапустите backend.

## 4. Как настроить webhook URL
В @CryptoBot:
1. **My Apps**
2. Выберите нужное приложение
3. Откройте **Webhooks**
4. Нажмите **Add webhook URL**

Используйте один из URL:

- Для гарант-сделок:
  `https://goldenshake.com/api/garant/cryptopay-webhook/`
- Для депозитов баланса:
  `https://goldenshake.com/api/coins/cryptopay-webhook/`

Если настраиваете оба сценария через разные приложения, укажите соответствующий URL в каждом приложении.

## 5. Какие права нужны
Приложение должно иметь стандартный доступ для работы Crypto Pay API:
- создание invoice;
- получение статусов invoice;
- отправка webhook уведомлений.

Дополнительных прав Telegram-бота для этого не требуется.

## 6. Как проверить, что всё работает
1. Создайте тестовый invoice в GoldenShake.
2. Оплатите его через CryptoBot.
3. Убедитесь, что backend получил webhook:
   - для гаранта — сделка переходит в оплаченный статус;
   - для депозита — баланс пользователя пополняется.
4. Если webhook не сработал:
   - проверьте `CRYPTOPAY_TOKEN` в `.env`;
   - проверьте правильность webhook URL в **My Apps → Webhooks**;
   - убедитесь, что сервер доступен по HTTPS;
   - проверьте логи backend на ошибки подписи webhook.
